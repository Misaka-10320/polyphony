  1. 2026.10.08周四 / 04

    第一章完成 · 社会问题如何被建构

    数字如何成为论据，
    问题如何成为问题？

    “事实”和“统计”也有形成、传播与被使用的过程，这会怎样改变我们研究社会问题的方式？

    从主张到回应

    建构主义把诉求表达、争论和制度回应当作经验研究对象。研究者可以暂时悬置对主张真假的裁定，观察谁提出问题、采用什么说服方式、要求谁负责，以及主张如何扩大或消退。

    数字也有社会过程

    统计要先决定定义、分类、记录与计算口径，随后又在媒体与机构中被挑选、比较和引用。研究数字怎样成为论据，并不等于断定数字虚假；资料的准确性仍需独立检验。

    教材以《〈児童虐待〉の構築》为例：它分析“虐待增加”的公共叙述如何与定义变化、关注提升、福利制度及统计案例的使用相连。这里分析的是问题被定义和制度化的过程，不是否认伤害。

    第一章收束为一条提问链：现象有什么社会作用？谁制定规则、认定越轨？谁把某种状况提出为社会问题，事实与数字又如何支撑这项主张？我把这条线索整理成下方的思维导图。

  2. 2026.10.07周三 / 03

    越轨研究 → 社会问题

    从“隐蔽越轨”
    到“社会问题建构”

    “默许、没有发现、法律空白，究竟哪一种算隐蔽越轨？”

    修正一个例子

    “隐蔽的越轨”以已有规则被违反为前提，但相关他人尚未把这个具体行为认定为越轨。论文已经抄袭，却被当作原创，是清楚的例子。已经认定违规、只是默许或不处罚，不能仅凭“未追究”归入这一类；若没有适用规则，也得先厘清判断依据。

    追问定义的过程

    社会问题建构主义把注意力放在谁提出诉求、如何命名、要求谁负责、机构怎样回应。以抑郁症公共议题为例，值得研究的是个人困境如何被提出为需要集体支持的问题；“被建构”并不意味着痛苦是虚构的。

    今天的收获：研究者可以暂时悬置一项主张的真伪，观察诉求和回应怎样发生；这只是限定研究对象，并非替主张背书。最后把功能主义、标签理论、建构主义整理为一张日语思维导图。

  3. 2026.10.06周二 / 02

    规则与社会认定

    行为发生了，
    社会如何认定它？

    从“投机倒把”的历史变化想到：越轨的边界会不会随着规则改变？

    这一例子提醒我区分行为、适用规则和社会评价。某类经营活动的法律身份改变，不代表旧罪名涵盖的所有行为都变得合法，更不能直接推断所有人都不再认为它有问题。

    守规则 · 未被认定同调行为
    违规 · 未被认定隐蔽的越轨
    守规则 · 被认定被错误指控
    违规 · 被认定被认定的越轨

    四格表让我看见“实际做了什么”和“别人认为他做了什么”之间的距离。一个人被称为越轨者，不能反推他一定违规；一次违规没有被发现，也不等于规则不存在。

  4. 2026.10.05周一 / 01

    两个理论入口

    从“它有什么作用”，
    到“谁说它是越轨”

    “機能主義？”“ラベリング理論？”——从日语教材里的两个术语开始。

    功能主义

    把家庭、学校等制度放进社会系统，考察它们产生了什么后果、如何与其他部分相连。“功能”不等于参与者的主观目的，更不等于道德上的正当。涂尔干、帕森斯和默顿提供了不同的分析线索。

    标签理论

    贝克尔把视线从“为什么有人违规”移向谁制定规则、谁有权贴标签，以及标签怎样改变一个人受到的对待。标签影响越轨身份和社会反应，却不能抹去对实际行为的考察。

    起点不是背下两个定义，而是发现：同一个现象，可以因问题的问法不同而呈现出完全不同的结构。

中心问题 / 01社会问题，
如何成为“问题”？

研究焦点从现象本身，逐步转向规则、主张与社会回应。

理论视角 · 同一现象的三种问法理論の視点 · 同じ現象への三つの問い
01 / FUNCTION

功能主义機能主義

一个现象对社会整体产生了什么后果？ある現象は社会全体にどんな結果をもたらすか。

  • 观察单位把家庭、学校、法律等制度放进相互关联的社会系统。観察単位家族・学校・法などの制度を、相互に関連する社会システムに位置づける。
  • 关键提问某种安排维持了什么、改变了什么？预期后果与意外后果要分开。中心的な問いある仕組みは何を維持し、何を変えるか。意図した結果と意図せざる結果を分ける。
  • 代表学者涂尔干、帕森斯、默顿；三人的问题意识并不完全相同。代表的研究者デュルケーム、パーソンズ、マートン。三者の関心は同一ではない。
  • 经典例子涂尔干指出，社会对犯罪的反应有时会重新确认群体规范。典型例デュルケームは、犯罪への社会的反応が集団の規範を再確認させる場合を論じた。
  • 边界“产生功能”不等于“道德上正当”；也要问谁承受了代价。限界「機能がある」は「道徳的に正しい」ではない。誰が負担を負うかも問う。
02 / LABEL

标签理论ラベリング理論

谁制定规则？谁有权把别人认定为越轨者？誰が規則を作り、誰が他者を逸脱者と認定する権限をもつか。

  • 代表学者霍华德·S·贝克尔：越轨不只在行为本身，也在他人对行为的反应。代表的研究者ハワード・S・ベッカー。逸脱は行為だけでなく、他者の反応とも結びつく。
  • 分析顺序规则如何产生 → 如何适用 → 谁被贴标签 → 其身份与处境怎样改变。分析の順序規則の成立 → 適用 → ラベル付け → 当人の地位や扱いの変化。
  • 两条轴线把“实际是否违反现行规则”与“是否被认定为越轨”分别判断。二つの軸「現行の規則に実際に違反したか」と「逸脱と認定されたか」を別々に判断する。
未违规 · 未认定違反なし · 認定なし同调行为同調行動
已违规 · 未认定違反あり · 認定なし隐蔽的越轨隠れた逸脱
未违规 · 被认定違反なし · 認定あり误判的越轨誤って告発された行動
已违规 · 被认定違反あり · 認定あり纯粹的越轨正真正銘の逸脱
  • 判别提醒违规却被发现但未处罚，不自动属于“隐蔽”；先看具体行为是否被认定。判別上の注意違反が発覚しても処罰されない場合は、直ちに「隠れた逸脱」にはならない。行為への認定を確かめる。
03 / CLAIM

建构主义構築主義

一种状况怎样被提出、命名并承认为社会问题？ある状態はいかに提起・命名され、社会問題として認められるか。

  • 代表学者斯佩克特与基特苏斯：社会问题是围绕某种状况提出诉求并作出回应的活动。代表的研究者スペクターとキツセ。社会問題を、ある状態をめぐるクレイムと応答の活動として捉える。
  • 诉求提出谁说“这是问题”？怎样描述损害、归因、提出改变要求？クレイム申し立て誰が「これは問題だ」と語り、被害・原因・変革要求をどう示すか。
  • 社会回应媒体、政府、专家、学校与组织如何接受、反驳或重新定义诉求？社会的反応メディア・行政・専門家・学校・団体は主張をどう受容、反論、再定義するか。
  • 研究策略暂时悬置主张真假，观察可记录的互动；这不是断言问题不存在。研究上の方針主張の真偽判断をいったん留保し、記録可能な相互作用を観察する。問題の不存在を意味しない。
  • 视角转移从“状况为什么发生”，转向“为何此时、由这些人、用这种语言说成问题”。視点の転換「状態はなぜ生じたか」から「なぜ今、この人々が、この言葉で問題化したか」へ。
经验研究 · 如何把理论变成可追踪的问题経験的研究 · 理論を追跡可能な問いにする
04 / METHOD

诉求如何展开クレイムをどう追うか

沿着主张、材料和回应，重建问题形成的过程。主張・資料・応答をたどり、問題化の過程を再構成する。

  1. 01提出者与对象谁发起诉求？向谁要求什么行动？提起者と宛先誰がクレイムを起こし、誰に何を求めるか。
  2. 02命名与修辞怎样定义范围、讲述损害、归责、使用口号或典型故事？命名とレトリック範囲、被害、責任をどう定め、標語や典型事例をどう使うか。
  3. 03支持与争论谁支持或反对？哪些解释获得可见度，哪些被边缘化？支持と論争誰が支持・反対し、どの解釈が可視化され、どれが周縁化されるか。
  4. 04制度背景媒体、政府、专业组织的惯例与利益如何塑造回应？制度的文脈メディア、行政、専門組織の慣行や利害は応答をどう形づくるか。
  5. 05事实与统计追问定义、分类、记录、分母、时间段与比较口径；数字又被谁引用？事実と統計定義、分類、記録、分母、期間、比較基準を確かめ、数字が誰に引用されるかを追う。
  6. 06结果与后续诉求怎样扩散、制度化、改变政策，或逐渐消退？結果とその後クレイムはどう広がり、制度化・政策化され、または沈静化するか。
05 / CASE STUDY

儿童虐待：一个案例児童虐待：一つの事例

上野加代子、野村知二《〈児童虐待〉の構築》（2002）上野加代子・野村知二『〈児童虐待〉の構築』（2002）

  1. A公共叙事自 1990 年代起，“虐待增加、严重化”被媒体、专家与民间团体反复提出。公的な語り1990年代以降、「虐待の増加・深刻化」がメディア、専門家、民間団体によって繰り返し語られた。
  2. B定义与识别虐待范围扩大、社会关注和通报增加，都可能抬高被记录的件数。定義と認知虐待の範囲の拡張、関心や通告の増加は、記録件数を押し上げうる。
  3. C机构与解释框架“家庭病理”的说法，也要放进少子化时代福利机构的处境中理解。制度と説明枠組み「家族の病理」という語りも、少子化時代の福祉機関の状況に置いて考える。
  4. D统计与典型案例选择哪些数字和极端个案，可能强化“恶化”叙事并压低其他解释。統計と典型事例どの数字や深刻な事例を選ぶかが、「悪化」の語りを強め、別の解釈を見えにくくしうる。
  5. E要追问的区别实际发生、被识别、被报告、被登记的增加，是同一件事吗？区別すべき増加実際の発生、認知、通告、記録の増加は、同じことなのか。
  6. F研究边界分析问题如何被建构，不等于否认伤害；关于制度动机的解释也须有证据。研究上の限界問題化の過程を分析することは被害の否定ではない。制度的動機の説明にも根拠が要る。
三条问题链功能主义问“造成什么后果”；标签理论问“谁制定并执行规则”；建构主义问“谁提出诉求、如何获得回应”。经验研究把三条问题链落实到材料、比较与证据上。三つの問いの連なり機能主義は「どんな結果をもたらすか」、ラベリング理論は「誰が規則を作り適用するか」、構築主義は「誰がクレイムを申し立て、どう応答されるか」を問う。経験的研究はそれらを資料・比較・証拠につなぐ。

三种提问方式

同一个现象，
换三个问题。

  1. 01 / 功能主义

    它对社会系统产生了什么后果？

  2. 02 / 标签理论

    谁制定规则，谁被认定为越轨者？

  3. 03 / 建构主义

    谁把它提出为公共问题，获得怎样的回应？
