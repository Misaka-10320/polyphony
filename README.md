# 复调 · POLYPHONY

Misaka10320 与 花間堂 / florahals 共同发表文章的静态网站。

## 2026-10-09 独立学习中心与国际政治词库
学习与作者作品分开，首页及全站导航设有“学习”入口。原作者页中的日志及思维导图链接自动转向新位置。
学习中心使用 CSS 渐变绘制气泡与细线 SVG 图标，开场浮入和弹性回落由浏览器动画实现，无新增图像、框架或后端。系统减少动态效果时显示静态气泡。
国际政治词库与社会学词库共用查询、分页、收藏、掌握状态和抽词复习逻辑；国际政治不显示日语版本。国际题源按招生年度记录，考试常在上一年12月举行，界面注明年份口径。
数据只纳入公开可读且明确归入初试名词解释分节的材料；课程名、代码不明确时保留来源标题并作说明。共享政治学科目须确认适用于国际类专业。题目有缺失、分值与数量不一致、疑似转录错误时在对应卷的备注中披露，无法合理确认的词不纳入。本站收录数不表示完整真题频次。

## 视觉标识
`assets/mark.svg` 是正式标志「叠框」：两张相交的纸页或影像画幅，中间保留四芒星，用于导航、浏览器图标和开场介绍。
其余方案保留为网站的编辑符号：`symbol-book.svg` 用于文章入口，`symbol-waves.svg` 用于双作者板块，`symbol-quotes.svg` 用于文学内容，`symbol-monogram.svg` 用于文章结尾，`symbol-aperture.svg` 用于摄影板块。所有符号均为矢量图，作为装饰时不参与正文朗读。

## 预览与发布
正式网址：https://misaka-10320.github.io/polyphony/ 。
旧 Cloudflare 地址（停止维护）：https://polyphony-journal.pages.dev/ 。
网站不需要构建步骤，发布时上传此文件夹的网页及资源即可。
未来新增文章时，增加文章 HTML 并更新对应作者目录。
未来新增学习日志时，在 `sociology-log.html` 的 `.sociology-timeline` 开头加入一个带有 `<time datetime="YYYY-MM-DD">` 的条目，并更新 `.sociology-count` 与学习入口的日期范围、记录数。每条记录区分当日问题、理解与修正；若有公开来源，附上链接。相应的日文译文加入 `sociology-log.js`，样式集中在 `sociology-log.css`。中文正文留在 HTML 中作为无脚本回退。
词库数据位于 `sociology-terms.json`，每个词条包含双语定义、学者、例子、易混点、关联词和来源。新增内容须同时提供中日文并核对引用；页面脚本、样式及数据的 URL 版本号随更新递增，避免缓存导致内容与界面不一致。词库按需加载并分批显示，无新增框架或后端。语言选择与学习日志、学习中心共用浏览器偏好；社会学与国际政治词库的收藏、掌握状态分别使用独立的本地存储，不跨浏览器同步。
目标校信息参考滋賀県立大学、同志社大学、京都府立大学的官方资料。明确标记的出题例仅指已核对的具体公开题，不代表固定考纲或考试频率。解说为独立整理的学习提纲，须按实际设问展开；示例用于说明概念。双语学习区域禁用浏览器自动翻译，防止干扰已校对的译文。
